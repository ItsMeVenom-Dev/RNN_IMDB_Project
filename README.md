# Simple RNN for Text Classification (IMDB Dataset)

This project implements a **Simple Recurrent Neural Network (RNN)** for sentiment analysis on the **IMDB movie reviews dataset**.  
It demonstrates the use of embeddings, RNN layers, and prediction pipelines.

---

## 📂 Project Structure

**│-- main.py**
**│-- embedding.ipynb**
**│-- prediction.ipynb**
**│-- simplernn.ipynb**
**│-- simple_rnn_imdb.keras**
**│-- README.md**




---

## 🚀 Features
- Implements **Simple RNN** for text classification.
- Uses **IMDB dataset** for sentiment analysis.
- Includes **word embeddings** and sequence preprocessing.
- Provides **notebooks** for:
  - Embedding visualization
  - Model training
  - Sentiment prediction
- Trained model saved in `.keras` format.
